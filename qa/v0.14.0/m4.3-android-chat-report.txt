CatLifePet M4.3 Android Streaming Chat QA Report
Date: 2026-07-22

Scope
- Native ChatActivity and RecyclerView message list; no Compose migration.
- Home entry named "和小猫聊聊"; floating-pet click behavior remains unchanged.
- Conversation list, new/select/delete, server history, streaming reply, stop, and retry.
- Loading, empty, offline, failed, and expired-session states.
- Room cache for conversations, server messages, and pending user sends.
- Shared encrypted login session with one forced refresh and retry after HTTP 401.

Persistence and interruption checks
- User text is written to Room before network transmission.
- Failed and stopped sends retain the original clientMessageId for idempotent retry.
- Activity recreation does not submit or display duplicate messages.
- Closing and reopening the Room database preserves failed pending text.
- SSE response-body interruption produces a retryable failure instead of hanging.
- Cancelling generation closes the OkHttp call and leaves a retryable pending message.

Toolchain decision
- Room 2.7.2 is pinned because it targets Kotlin 2.0, matching the project's Kotlin
  2.0.21 compiler. Room 2.8.4 is built with a newer Kotlin toolchain and was rejected
  after a repeat-build schema compatibility failure.
- Room schema version 1 is exported under app/schemas and checked into Git.

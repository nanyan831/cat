CatLifePet M5.1 Controlled Companion Memory QA Report
Date: 2026-07-22

Scope
- Explicit-only cloud memory kinds: nickname, preferred_address, routine, preference.
- Authenticated list, create, delete-one, and delete-all memory endpoints.
- Delete-all cloud conversation endpoint and Android data-management control.
- Android native MemoryActivity with add, list, delete, clear, loading, failure, and
  expired-session states.
- Prompt context contains only a bounded summary, selected active memories, and recent
  completed messages.

Privacy and prompt controls
- Chat text is not automatically promoted to durable memory.
- Memory creation requires an explicit authenticated request from the user.
- Cross-account source conversations and memory deletion are rejected as not found.
- Prompt memory order is deterministic and deleted rows are excluded immediately.
- Instructions are capped at 4,000 characters; recent message content is capped at
  12,000 characters and 20 messages; at most eight memories are selected.
- Conversation summaries are deterministic transcript snippets capped at 1,800
  characters and exclude the latest 20 messages already sent as recent context.
